# Dashboard de Análise de Dados com Excel 📈

Este projeto foi desenvolvido durante o bootcamp **Santander 2024 - Excel com IA**, realizado na [DIO](https://www.dio.me/). O foco foi a criação de um painel de controle (Dashboard) interativo para suporte à tomada de decisão.

## 📊 O Dashboard
O projeto consiste em uma planilha que transforma dados brutos em um painel visual com os seguintes componentes:

* **KPIs Principais**: Indicadores de desempenho (Ex: Total de Vendas, Ticket Médio, Crescimento Mensal).
* **Gráficos Dinâmicos**: Visualização de tendências e distribuições.
* **Segmentação de Dados (Slicers)**: Filtros interativos para análise por data, região ou categoria.
* **Design Limpo**: Foco na experiência do usuário (UX) para leitura rápida de dados.

## 🤖 O Papel da IA no Desenvolvimento
A Inteligência Artificial (ChatGPT/Copilot) foi utilizada como um "copiloto" de programação e lógica:
1.  **Geração de Fórmulas**: Auxílio na criação de fórmulas complexas de agregação (ex: `SOMASES` ou `PROCX`).
2.  **Sugestão de Gráficos**: Consulta à IA sobre qual o melhor tipo de gráfico para representar cada conjunto de dados.
3.  **Tratamento de Dados**: Scripts e lógica para limpeza de valores nulos ou duplicados.

## 🛠️ Tecnologias e Ferramentas
* **Microsoft Excel**: Base de dados e interface do dashboard.
* **Tabelas Dinâmicas**: Para resumo e processamento rápido dos dados.
* **IA Generativa**: Para otimização de tempo e resolução de problemas lógicos.

## 🚀 Como visualizar o projeto
1.  Faça o download do arquivo `.xlsx` presente neste repositório.
2.  Abra no Microsoft Excel (recomenda-se versão 2019 ou superior).
3.  Utilize os botões de **Segmentação de Dados** para interagir com os gráficos.
